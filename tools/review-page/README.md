# Review page

`ads-phone.html` is the template for the phone-sized ad review page (https://claude.ai/artifact/EwVYnHsfAWgSiyjdAXVyzy).
Every video sits in a ~330 px phone frame (classes: phone, feed = 4:5, sq = 1:1), tap to play, one at a time.
To update it: copy small 720 px copies of the renders into a `v/` folder next to it, with poster JPEGs, then republish with the Artifact tool (root = that folder, files = every v/ file).
