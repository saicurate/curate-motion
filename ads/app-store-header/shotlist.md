# App Store header: shot list (G2)

Times in seconds on a 15 s loop (timeline.ts); data in shots.ts. No music: the placements are muted,
so state changes sit on the shot list's own rhythm (≈ every 1.6–4 s), not a beat map. Last frame = first.
