# config/

Project-wide settings as data, each with a zod schema in `schemas/` and a JSON Schema in
`catalog/schemas/` (generated by `tools/catalog build`; `tools/catalog validate` checks them).

| File | What | Schema |
|---|---|---|
| `voice.json` | The voiceover: the default `mode` (`captions` / `human` / `tts`), the caption presets, the TTS profiles (`tts.use` = the one in use), the paid-TTS spend cap, timing | `schemas/voice.ts › VoiceConfig` |

- **Goes here:** settings that change how every ad behaves, that a person should be able to flip
  with one edit.
- **Doesn't:** secrets (→ AWS SSM; record only the parameter NAME), per-ad settings (→ `ads/<ad>/ad.json`), media.
- **Example:** captions only → TTS for every ad: change `"mode": "captions"` to `"mode": "tts"` in
  `voice.json`. Full table in AGENTS.md › "How to change the voice".
