# decisions/

One short markdown file per decision, numbered, never rewritten: if a decision changes, add a new
file that supersedes the old one and say so in both. Format: context, decision, why, consequences.

- Goes here: choices a new agent would otherwise re-litigate (storage, tools, naming, personas).
- Doesn't: how-tos (AGENTS.md), designs (ARCHITECTURE.md), changes (CHANGELOG.md).
- Example: `0001-s3-not-git-lfs.md`. Next number: look at the highest and add one.
